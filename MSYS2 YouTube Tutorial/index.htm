Download msys2-x86_64 installer here:

https://www.msys2.org/

Update and Prepare MSYS2 MINGW64

pacman -Syu

When prompted, close the window after it finishes, then reopen MSYS2 MSYS and run again:

pacman -Su

Now everything is fully updated.

Install Needed Packages;

  • nasm - Assembler
  • qemu - Emulator (we’ll use qemu-system-i386 for 16-bit code)
  • make - simplifies rebuilds, has functions we will call
  • gdb - Gnu Debugger
  • vim - simple built-in editor, has functions we will call
  • bc - convert to binary

pacman -S mingw-w64-x86_64-nasm mingw-w64-x86_64-qemu make gdb vim bc

WARNING: Do Not experiment without protection!
Do not tweak these values and run on a hard drive or Flash drive without an Emulator. You could overwrite data.

; Define where in memory to load kernel
mov ah, 2 ; Function: Read sector from disk
mov al, 1 ; Number of sector to read
mov cx, 2 ; Cylinder# ch=0x00 / Sector# cl=0x02
mov dx, 0 ; Head# dh=0x00 / Drive# dl=0x00
mov bx, 0x7E00 ; Load address immediately after this one
int 19 ; BIOS disk interrupt
jmp bx ; Jump to the loaded extended code

 

Assemble Bootloader:
