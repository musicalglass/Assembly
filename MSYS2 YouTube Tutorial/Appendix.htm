Description Summary — Instruction Prefixes

Segment Override Prefixes

0x2E Force CS segment Use CS: instead of the default segment for memory addressing.
0x36 Force SS segment Uses SS: explicitly (commonly used when accessing stack variables).
0x3E Force DS segment Forces DS: (often redundant because DS is already the default segment).
0x26 Force ES segment Uses ES: for memory access (important for MOVS, STOS, SCAS).
0x64 Force FS segment Uses FS: (common for thread-local storage in protected mode).
0x65 Force GS segment Uses GS: (often used by OS kernels for per-CPU data).

Repeat Prefixes

0xF2 REPNE / REPNZ Repeat the string instruction while ZF = 0; stops when ZF becomes 1 or CX reaches zero.
0xF3 REP / REPE / REPZ

Repeat while ZF = 1, or repeat unconditionally for MOVS/STOS;
CX is decremented automatically.

These prefixes apply only to string instructions such as MOVSB, MOVSW, CMPSB, SCASB, STOSB, and LODSB.

LOCK Prefix

0xF0 LOCK Makes the next memory operation atomic,
preventing interruption by other processors.

Size Override Prefixes

0x66 Operand-size override Switches the instruction’s operand size (e.g., 16-bit ? 32-bit arithmetic).
0x67 Address-size override Switches the memory addressing mode (e.g., 16-bit offsets ? 32-bit offsets).

 

ModR/M Byte Structure

The ModR/M byte is an extra instruction byte used by many x86 opcodes to specify which register or memory address the instruction operates on. It contains three fields: mod (addressing mode), reg (register or sub-opcode selector), and r/m (register or memory addressing method). Together, these fields allow a single opcode to work with many different operand types, making the instruction set compact and flexible.

The ModR/M byte is:
7 6 | 5 4 3 | 2 1 0
--------------------------------
| mod | reg | r/m |
--------------------------------mod (2 bits) = addressing mode
reg (3 bits) = register or sub-opcode selector
r/m (3 bits) = register or memory addressing method

500 mod Addressing Type 00: Memory, no displacement (except rm=110)
01: Memory, 8-bit displacement
02: Memory, 16-bit displacement
03: Register direct (no memory)
501 reg Register or /digit In GRP instructions: reg = /digit selects the sub-instruction.
Otherwise: selects register operand.
502 r/m Memory/Register specifier Determines addressing mode when mod<3,
or register when mod=3.

SIB Byte Structure (Scale-Index-Base)

The SIB byte is an extra addressing byte used in 32-bit x86 instructions to describe complex memory addresses. It contains three fields: scale (multiplier for the index), index (the register to be scaled), and base (the starting register). Together, these fields let an instruction access memory using the formula Base + Index×Scale + displacement. The SIB byte only appears in 32-bit and 64-bit addressing modes and is never used in 16-bit real mode.

600 [7:6] scale Multiplier for index register: 1, 2, 4, 8
601 [5:3] index Index register (ESP invalid)
602 [2:0] base Base register (EBP special case)
